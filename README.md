# 恶魔叮 Codex Pet

这是一个 Codex 自定义宠物，形象来自《洛克王国世界》中的恶魔叮。

## 目录结构

```text
EMoDing-CodexPet/
  README.md
  emoding-world/
    pet.json
    spritesheet.webp
```

真正需要安装的是 `emoding-world` 这个文件夹，请保持里面的 `pet.json` 和 `spritesheet.webp` 放在一起。

## 放到哪个目录

把 `emoding-world` 整个文件夹复制到 Codex 的 pets 目录：

Windows:

```text
%USERPROFILE%\.codex\pets\emoding-world\
```

macOS / Linux:

```text
~/.codex/pets/emoding-world/
```

## 怎么启用

1. 打开 Codex。
2. 进入外观设置。
3. 找到宠物或 Pet 相关选项。
4. 选择 `恶魔叮`。
5. 如果没有立刻出现，重启 Codex 后再进入外观设置查看。
